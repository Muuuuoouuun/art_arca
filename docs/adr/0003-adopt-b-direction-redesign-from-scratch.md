# ADR 0003 — B(Collector's Cabinet) 방향 채택, 실제 버전은 처음부터 새로 디자인

- 상태: 채택(Accepted) — 방향과 구조만. **시각 디자인은 미착수이며 매우 시급함.**
- 날짜: 2026-10-28
- 대체: ADR 0002의 "어느 시안도 채택하지 않음" 상태

## 맥락
- ADR 0002에서 art_hub와 art_arca를 섞은 시안 A/B/C를 만들었습니다.
- 준혁님이 **B · Collector's Cabinet** 쪽을 골랐습니다. 다만 B 시안을 다듬는 것이 아니라 **아예 새롭게** 만들기로 했습니다.
- 이번 단계의 지시는 "방향성, 구조만 짜고 디자인이 매우 간절히 필요하다로 정리"입니다.

## 결정
1. 제품 방향은 B입니다: 번호 매긴 **레지스트리 목록**, **선반 + 라벨 카드** 큐레이션, 밝은 종이 톤 아카이브, 마지막의 **가이드 허브 진입**.
2. B 시안의 **코드와 시각 값(색 하드코딩, 폰트 크기, 그림자 수치)은 그대로 쓰지 않습니다.** 아이디어와 정보 구조만 가져갑니다.
3. 방향, 원칙, IA, 페이지별 섹션, 컴포넌트 목록, 데이터 요구, 반응형 규칙, 열린 질문은 `docs/design/B-DIRECTION.md`에 정리합니다.
4. `/mockups/b-structure`에 회색 박스 **구조 와이어프레임**을 둡니다. "구조 와이어프레임 · 디자인 미적용"을 화면에 표시합니다. 프론트 전용이고 API 호출이 없습니다.
5. 실제 페이지(`/`, `/exhibitions` 등)는 이번에 **바꾸지 않습니다.** 디자인 산출물(B-DIRECTION.md 상단 체크리스트)이 나온 뒤 `DESIGN-ROADMAP.md` 트랙(T1 토큰 → T2 셸 → …) 순서로 구현합니다.
6. 가짜 수치(전시 상세의 Signals/Save Rate/Revisit/Salon Seats 등)는 새 버전에 넣지 않습니다.

## 결과
- 좋은 점: 구조가 먼저 합의되어, 디자이너가 화면별 정보 단위를 바로 받아 작업할 수 있습니다.
- 위험: **시각 디자인이 비어 있어 이 상태로는 출시할 수 없습니다.** 디자인 담당·일정이 정해지지 않았습니다. 가장 먼저 해결해야 할 일입니다.
- `/mockups/*`는 여전히 빌드에 포함됩니다(noindex). 배포 전 제거하거나 환경 플래그로 막아야 합니다.
- A, C 시안은 참고용으로 남기되 더 발전시키지 않습니다.
